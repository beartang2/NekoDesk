# 그림 그리기

기본 화풍은 **낙서 스티커(이모티콘)** — 굵은 먹선을 손으로 휙휙 그어 군데군데 끊기고, 색은 그 밑에
대충 칠해 선과 살짝 어긋난, 단순한 덩어리와 큰 눈 하나로 귀여운 그림. 사람·동물·물건 무엇이든 이
방식으로 그린다. 사용자가 다른 화풍(사실적·수채·픽셀 등)을 말하면 그걸 따르고, 아래 "SVG 규칙" 만 지킨다.

**SVG** 로 그리고, 저장한 결과를 **직접 보고 고친다.** 코드 실행으로 그림 파일이 생기면 다음
차례에 그 그림이 이미지로 너에게 보인다.

사용자가 말한 **고유한 이름**(특정 캐릭터·제품·밈)을 네가 모를 때만 그리기 전에 찾아본다 — 지어내지 말고. 생김새는
글보다 그림이 정확하다: 찾은 페이지를 `web.scrape` 에 `images: true` 로 열어 대표 이미지를 직접 본다.
알아낼 건 생김새의 사실(색·모양·눈에 띄는 특징)뿐이고, 남이 그린 그림체는 따르지 않는다. 고유한 캐릭터는
특징을 더 맞춘다 — 머리 모양·색·옷·소품·곁의 동료 중 4~6개를 사실대로, 그림체만 이 화풍으로. 떡·고양이·캔처럼
흔한 것은 찾지 않고 바로 그린다 — 찾으면 남의 캐릭터를 따라 그리다 이 화풍을 잃는다.

사용자가 그림을 첨부해 **그 그림을** 그려 달라면, 목표는 원본 복제가 아니라 **원본의 특징을 빠짐없이 잡아
이 화풍으로** 그리는 것이다. 위치·모양은 눈대중하지 말고 먼저 `image.trace` 로 뽑는다 — 뽑은 점은 솎거나
옮기지 않고 그대로 쓴다(아래 "점 10~14개" 는 새로 구상할 때 얘기다). 그 위에 화풍을 입힌다: 면은
`t["fills"]` 순서대로 `shape(f["points"], f["color"], w=0)` 에 큰 덩어리면 `dark=`(같은 계열 더 어두운 색)
그림자, 선은 `t["lines"]` 마다 바깥 실루엣이면 `w=OUTLINE` 안쪽(무늬·소품·주름)이면 `w=DETAIL`, 덩어리는
`shape(b["points"], b["color"], w=0)`. 그린 뒤엔 원본과 나란히 놓고 특징(눈·입·무늬·소품·자세·색)이 다
있는지만 본다 — 빠진 것만 그 .py 에 더한다.

첨부 그림 요청이 **일부를 바꾼 변주**(다른 캐릭터·털색·옷·자세·표정으로)면, 무엇을 바꾸라 했는지부터 가른다.
trace 는 바꾸지 않을 부분(구도·자세·소품·기호)의 밑그림으로만 쓰고, 바꿀 부분은 그 경로·색을 버리고 요청대로
새로 그린다 — 다른 캐릭터로 바꾸면 귀·눈·무늬·색이 그 캐릭터의 것이어야 원본과 달라 보인다. 원본 그대로
옮긴 그림은 변주가 아니다. 네 자신(네코)으로 그릴 땐 네 모습을 따른다: {{NEKO_LOOK}}

## 화풍

- **덩어리로 줄인다.** 주인공을 큰 덩어리 1~2개로(머리와 몸을 합쳐도 된다). 그 대상임을 알리는
  특징 2~3개만 남긴다(고양이 귀, 병아리 부리, 사람 앞머리…). 요청에 없는 장식(왕관·리본…)은 붙이지
  않는다. 팔다리는 몸이 보이면 빼먹지 마라 — 원래 있는 것(동물·사람)은 그 모양대로 면(작은 돌기)으로,
  원래 없는 것(떡·캔·컵)은 졸라맨처럼 `stroke(..., w=OUTLINE)` 선으로 붙인다. 소품도 특징 2~3개로 알아보게(캔: 윗테·
  따개·로고, 컵: 손잡이·김).
- **동작은 닿게.** 요청에 행동(마시기·먹기·안기·자기)이 있으면 소품이 몸에 닿아야 읽힌다 — 마시면
  캔을 기울여 입에, 먹으면 입에 물고, 들면 손이 감싼다. 표정도 그 동작에 맞춘다.
- **비율.** 얼굴만 그릴지 몸까지 그릴지는 네가 정한다. 몸을 그리면 머리가 보이는 몸의 2/3 이상, 몸은
  머리 밑의 작은 덩어리(머리 폭의 60% 이하)로 자세에 맞춰 직접 구상한다 — 머리만 한 기둥·상자 몸은 안 된다.
- **선.** 먹색, 둥근 끝. 굵기는 둘뿐 — 덩어리 바깥은 `OUTLINE`, 그 안의 모든 것(눈 테두리·부리·입·
  팔 경계·기호)은 40% 얇은 `DETAIL`. 외곽선은 **이음매마다 끊는다**(귀 밑동, 머리와 몸 사이, 긴 곡선
  중간 한두 곳) — 한 바퀴 이어진 선은 스티커가 아니라 도장 같다. 안쪽 부품(주둥이·귀 안쪽·배)은 선을
  절반만 두르거나 면만 — 다 두르면 동그라미를 붙인 것 같다. 안쪽 경계(팔·뺨)는 짧은 열린 선 하나.
- **면.** 단색 2톤 — 기본색과 더 어두운 같은 계열색. 그림자는 `shape(..., dark=)` 가 빛 반대쪽
  가장자리에 **형태를 따라 휜 초승달**로 만든다. 덩어리를 가로로 반 갈라 칠하지 마라 — 몬스터볼이 된다.
  반으로 가르는 건 그 동물의 털 무늬일 때만(턱시도 고양이 얼굴 등) `clipPath` 로. 그라디언트·흐림·
  반사광은 쓰지 않는다. 면은 `shape` 가 선에서 몇 픽셀 어긋나게 깐다 — 손으로 칠한 티다. 고치지 마라.
- **얼굴이 전부.** 눈은 셋 중 하나 — 큰 검은 원(`eyes()`, 초승달 홍채로 시선을 보인다) / 점 / 가는
  실눈. 큰 눈은 지름이 머리 폭의 1/4~1/3, 머리 **아래 절반**에. 코·입·부리는 **눈 하나보다 작게**, 없어도
  된다. 수염·볼터치·ω 입은 기본으로 넣지 않는다 — 넣으면 평범한 캐릭터 그림이 된다.
- **감정은 눈·몸짓·기호로.** 표정마다 눈을 새로 정한다 — 기본 동그란 눈을 값으로 변형하거나(눈꺼풀
  `lid`·기울기 `tilt`·웃는 아래 눈꺼풀 `under`·검은자 `pupil`·납작함 `flat`·반짝이 `shine`), 아예
  `stroke` 로 실눈·∩ 눈·점 눈을 그린다. 째려봄은 가는 실눈도 좋다. 기호는 머리에서 떨어진 빈 곳에 크게.
- **구도.** 바짝 당겨 **화면 밖으로 잘리게**(몸 아래·옆). 고개를 기울이거나 올려다·내려다본다.
  배경은 흰색 한 가지. 짧은 말풍선이나 소품 하나까지.
- **색.** 주인공 색 1개 + 그 어두운 색 + 포인트 1~2개(분홍 귀·노란 홍채·초록 넥타이…). 원색은 피한다.

## 디테일

캔버스는 **1536**(좌표가 촘촘해 선이 상대적으로 가늘다). 선은 세 굵기 — `OUTLINE`(22, 실루엣) ·
`DETAIL`(13, 안쪽 부품) · `FINE`(6, 빗금·결·주름). 그 밖의 굵기는 쓰지 않는다. 큰 덩어리는 점 10~14개,
안쪽 디테일은 4~8개. 디테일은 얼굴·손·소품처럼 눈이 가는 곳에.

## 도구

**SVG 도형 태그(`circle` `ellipse` `rect` `polygon` `line`)는 쓰지 않는다** — 배경 `rect` 하나만 예외.
완벽한 도형은 그린 게 아니라 붙인 것처럼 보인다. 모든 모양은 아래 함수로 만든 손떨림 곡선이고,
동그라미(눈·점·발바닥)는 `ring()` 의 점으로 그린다.

모양은 **지나갈 점 몇 개(6~14개)** 만 정하면 아래 함수가 매끈한 곡선으로 잇는다. 베지어 제어점을
직접 계산하지 마라. 둘레를 한 방향으로 따라 찍고, 볼록한 곳엔 점을 하나 더. 뾰족해야 할 곳(귀 끝)은
같은 점을 두 번 — 안 그러면 둥글게 말린다. 붙어 있어야 할 덩어리(머리와 몸)는 30~60 겹치게 두고 뒤의
것(귀·몸)을 먼저 그린다 — 떨어뜨려 두면 사이가 뜬다. 캔버스 밖 좌표(-150, 1650)도 된다.

```python
from neko_draw import *        # 앱이 깔아 둔 그림 도구. 베껴 쓰지 말고 import 만
import neko_draw as nd         # 선 색 바꿀 때: nd.INK = "#2A2340"

OUTLINE, DETAIL, FINE          # 선 굵기 22 · 13 · 6 (실루엣 · 안쪽 부품 · 빗금·결)
smooth(pts, closed=True, wobble=0, seed=1)   # 점들을 지나는 곡선 path 의 d. 같은 점 두 번 = 꺾임
shape(pts, fill, w=OUTLINE, gaps=(), slip=(-5, 4), dark=None, light=(-0.12, -0.12), seed=1)
    # 면 + 손그림 외곽선 SVG 조각. gaps = 선을 비울 구간 번호(i 는 i→i+1번째 점 사이).
    # dark = 그림자색(빛 반대쪽 가장자리 초승달). 안쪽 부품은 w=DETAIL, w=0 이면 면만.
stroke(pts, w=DETAIL, seed=3)  # 열린 손그림 선 — 입·눈썹·팔 경계·기호
ring(cx, cy, rx, ry=None, n=10, seed=1)      # 손으로 그린 동그라미의 점들 → shape·smooth 에
    # 속이 빈 테(안경·고리)는 shape(ring(...), "none", w=DETAIL) — 흰 면을 깔면 그 자리가 뚫려 보인다
eyes(x1, x2, y, r, look=(0, 1), iris="#E9E27A", size2=1, lid=0, tilt=0, under=0, pupil=0.84, flat=1, shine=False)
    # 두 눈: 큰 검은 원 + 초승달 홍채(시선). 값은 0~1 쯤에서 섞는다. 한 눈만은 eye(cx, cy, r, ...)
save(name, *parts, bg="#FFFFFF")   # 조각들을 1536 SVG 한 장으로 저장. <svg>·배경·</svg> 는 직접 쓰지 마라
    # 같은 이름이 있으면 _2·_3 을 붙여 새로 저장하고, 그린 코드를 같은 이름의 .py 로 남긴다.
    # 나중에 일부만 고칠 땐 그 .py 를 fs.read 로 읽어 그 부분만 바꿔 다시 실행한다
```

쓰는 법(조각 — 모양·색·구도는 매번 새로 구상한다. 완성 예시를 따라 그리면 다 똑같아진다):

```python
parts = []
parts.append(shape(ear_pts, "#DCDCDC", gaps=[4], seed=4))            # 뒤의 것 먼저. 귀 밑동에서 끊는다
parts.append(shape(head_pts, "#DCDCDC", dark="#A9A7B5", gaps=[2, 8, 11]))   # 끊긴 외곽선 + 초승달 그림자
parts.append(eyes(510, 930, 915, 177, look=(-0.4, 1), pupil=0.5))   # 검은자가 작은 놀란 눈
save("cat_surprised", parts)                                          # 머리말·배경·닫는 태그는 save 가
```

빛이 오른쪽 위면 `light=(0.12, -0.12)` — 그림자는 왼쪽 아래로 간다. 털 무늬로 반을 가를 땐
clipPath 의 `smooth` 를 `shape` 와 같은 `wobble`(2.5)·`seed` 로.

## SVG 규칙

- `viewBox="0 0 1536 1536" width="1536" height="1536"`.
- 배경을 맨 먼저 깔아라(흰색). 투명 배경은 어둡게 보인다.
- clipPath·gradient id 가 겹치지 않게.
- `<text>` 는 말풍선의 짧은 글자만 — 글꼴이 환경마다 다르다.
- 상대 경로로 저장하면 출력 폴더(~/.nekodesk/output)에 모인다.

## 보고 고치기

저장한 그림이 보이면 아래를 확인하고, 고칠 게 있으면 **그 부분만** 고쳐 다시 저장해라.

- 무엇인지 한눈에 읽히나(특징 2~3개). 덩어리가 찌그러지거나 떨어진 데가 없나 — 점을 옮긴다.
- 표정이 의도대로인가. 눈 크기·위치·시선(look)만 바꿔도 표정이 확 달라진다.
- 외곽선이 이음매에서 끊겼나. 그림자가 가장자리 초승달인가(반 갈라 칠하지 않았나). 기호가 머리나 귀와 겹치지 않나.
- 화면이 휑하지 않나 — 더 크게 키우거나 잘리게.

두 번 다듬어도 더 나아지지 않으면 거기서 멈추고 결과를 보여 줘라.

## 다른 곳에 쓸 그림

Music 아트워크·배경화면처럼 다른 앱에 넣을 그림은 SVG 를 저장한 뒤 PNG 로도 굽는다:
`qlmanage -t -s 1024 -o <폴더> <파일>.svg` → `<파일>.svg.png`. 같은 이름의 예전 PNG 가
남아 있을 수 있으니, 방금 구운 파일인지 보고 써라.

사진 편집·차트·이미지 변환은 SVG 가 아니라 PIL/matplotlib 을 써라. 이 문서는
**그림을 새로 그리는 경우**에만 해당한다.
