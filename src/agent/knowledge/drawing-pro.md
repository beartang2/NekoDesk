# 그림 그리기

도형을 쌓은 그림이 아니라 일러스트레이터가 그린 듯한 부드러운 벡터 그림을 목표로 한다.
**SVG** 로 그리고, 저장한 결과를 **직접 보고 고친다.** 코드 실행으로 그림 파일이 생기면
다음 차례에 그 그림이 이미지로 너에게 보인다.

## 그리기 전에 정할 것

1. **구도** — 주인공이 무엇이고 화면의 몇 %(보통 55~70%)를 차지하는지, 어디를 보는지.
2. **광원** — 보통 왼쪽 위. 이후의 밝은 면·그림자·하이라이트가 전부 이 방향을 따른다.
3. **팔레트** — 주색 2~3개 + 중립색 1~2개. 색마다 세 단계를 미리 정해라:
   하이라이트(더 밝고 따뜻하게) · 기본 · 그림자(더 어둡고 살짝 차갑게, 채도는 약간 올려).
   순검정·원색(#000, #FF0000)은 쓰지 마라. 가장 어두운 색은 남색·고동색 계열로.

## 기법

- **실루엣은 path 로.** 머리·몸·귀·꼬리처럼 유기적인 형태는 cubic Bézier(`C`·`S`)로 이은
  닫힌 path 하나로 그려라. 원·타원을 겹쳐 붙이면 이음매가 생겨 장난감처럼 보인다.
  점은 적게, 곡선은 매끈하게(이웃한 제어점이 한 직선 위에 오게).
- **명암 3단.** 기본 면은 `radialGradient` 로(fx·fy 를 광원 쪽에), 그림자 면은 광원 반대편에
  얹고 `clipPath` 로 본체 안에 가둔다, 하이라이트는 광원 쪽에 작게 — 흐림(blur) 필터와
  opacity 0.4~0.6 을 주면 유리구슬처럼 번들거리지 않는다.
- **바닥 그림자.** 주인공 아래 납작한 타원 + `feGaussianBlur`(stdDeviation 10~20), opacity 0.15~0.25.
  이것 하나로 그림이 땅에 선다.
- **선.** 외곽선은 검정이 아니라 그 면의 그림자색보다 더 어두운 같은 계열색. 선 없이 면만으로
  가도 좋다 — 한 그림 안에선 통일. 선을 쓴다면 아래 "선화" 를 따른다.
- **얼굴·디테일.** 눈엔 흰 반사광 두 개(큰 것·작은 것), 볼터치는 가장자리가 사라지는
  radialGradient. 디테일은 큰 면이 다 자리 잡은 뒤에 얹어라.
- **배경.** 단색 대신 은은한 `linearGradient` + 크고 흐린 형태 두세 개로 깊이를 준다.
  주인공보다 채도·대비를 낮춰 주인공이 먼저 보이게.
- **대칭.** 반쪽만 그리고 `<g transform="translate(1024 0) scale(-1 1)">` 안에 `<use>` 로 뒤집어라.

## 선화

`stroke` 는 처음부터 끝까지 굵기가 같아서 스티커처럼 보인다. 손으로 그린 선은 강약이 있고
끝이 가늘어진다.

- **실루엣 강약.** 외곽선 색으로 채운 같은 모양을 광원 반대쪽(오른쪽 아래)으로 3~5 밀어
  본체 **뒤에** 깔고, 본체엔 얇은 stroke(2~3)만. 그림자 쪽은 굵고 빛 쪽은 가늘어진다.
- **짧은 선은 붓선으로.** 수염·눈썹·감은 눈·입·털결·발가락·주름은 stroke 가 아니라
  아래 `brush()` 로 만든 **채운 면**이다. 양 끝 굵기 0.5~1, 가운데 4~10.
- **겹침.** 뒤에 있는 것(꼬리·뒷다리·뒤쪽 귀)을 먼저 그리고 앞의 것으로 덮는다. 뒤의 선은
  앞의 형태에 닿는 곳에서 끝나야지, 앞 형태 위로 이어지거나 잘린 끝이 보이면 안 된다.
  이어진 한 덩어리(머리+귀, 몸+꼬리 뿌리)는 닫힌 path 하나로 그려 이음매를 없앤다.
- **안쪽 선은 열어 둔다.** 몸 위의 앞발·볼살·배는 외곽선을 다 두른 도형을 붙이지 말고, 형태가
  꺾이는 쪽에만 짧은 붓선 한두 개. 나머지 경계는 명암 차이로 보이게 둔다.
- **직선 금지.** 유기적인 실루엣엔 `L`·`H`·`V`·`rect`·`polygon` 을 쓰지 마라. 곧아 보이는
  변(몸통 옆선, 귀 가장자리)도 살짝 휜 `C`/`Q` 로. 뾰족한 끝(귀 끝)만 꼭짓점을 둔다.

```python
from math import sin, pi

def brush(p0, c, p1, w=(1, 6, 1), n=24):
    """p0 에서 p1 까지 c 쪽으로 휘는 붓선. w = 시작·가운데·끝 굵기. 채워 그릴 path 의 d."""
    left, right = [], []
    for i in range(n + 1):
        t = i / n
        x = (1-t)**2*p0[0] + 2*(1-t)*t*c[0] + t*t*p1[0]
        y = (1-t)**2*p0[1] + 2*(1-t)*t*c[1] + t*t*p1[1]
        dx = 2*(1-t)*(c[0]-p0[0]) + 2*t*(p1[0]-c[0])
        dy = 2*(1-t)*(c[1]-p0[1]) + 2*t*(p1[1]-c[1])
        k = (dx*dx + dy*dy) ** 0.5 or 1
        h = (w[0]*(1-t) + w[2]*t + (w[1] - (w[0]+w[2])/2) * sin(pi*t)) / 2
        left.append((x - dy/k*h, y + dx/k*h))
        right.append((x + dy/k*h, y - dx/k*h))
    return "M" + " L".join(f"{x:.1f} {y:.1f}" for x, y in left + right[::-1]) + " Z"

# f'<path d="{brush((300, 420), (330, 380), (370, 410), (1, 8, 1))}" fill="{선색}"/>'
```

```svg
<use href="#shape" fill="{선색}" transform="translate(4 5)"/>                  <!-- 실루엣 강약: 뒤에 -->
<use href="#shape" fill="url(#body)" stroke="{선색}" stroke-width="2.5"/>   <!-- 본체 + 얇은 선 -->
```

## SVG 규칙

- `viewBox="0 0 1024 1024" width="1024" height="1024"`. 세밀한 곡선에 여유가 있다.
- 배경을 맨 먼저 깔아라. 투명 배경은 어둡게 보인다.
- gradient·filter·clipPath·재사용 path 는 `<defs>` 에 모으고 id 가 겹치지 않게.
- filter 는 그림자·하이라이트·배경 흐림에만. 남발하면 그림 전체가 뿌옇다.
- `<text>` 는 꼭 필요할 때만 — 글꼴이 환경마다 다르다.
- 상대 경로로 저장하면 출력 폴더(~/.nekodesk/output)에 모인다.

## 보고 고치기

저장한 그림이 보이면 아래를 확인하고, 고칠 게 있으면 **그 부분만** 고쳐 다시 저장해라.

- 형태: 비율·대칭·이음매가 의도대로인가. 뭔가 빠지거나 잘리지 않았나.
- 선: 굵기가 한결같지 않은가. 끝이 뭉툭한 선, 겹친 곳에 남은 이음매, 직선 변이 없는가.
- 명암: 밝은 면과 그림자가 한 광원을 따르는가. 하이라이트가 과하지 않은가.
- 색: 탁하거나 너무 쨍하지 않은가. 주인공이 배경에서 분리돼 보이는가.

두 번 다듬어도 더 나아지지 않으면 거기서 멈추고 결과를 보여 줘라.

## 기법 조각 (완성 그림이 아니라 쓰는 법. 모양·색·구도는 주제마다 새로 구상해라)

완성된 예시를 주면 무엇을 그려도 그 예시를 색만 바꿔 다시 그리게 된다. 그래서 조각만 둔다.

```svg
<defs>
  <!-- 입체 면: 광원(왼쪽 위) 쪽에 fx·fy -->
  <radialGradient id="body" cx="0.42" cy="0.4" r="0.7" fx="0.3" fy="0.26">
    <stop offset="0" stop-color="{하이라이트}"/>
    <stop offset="0.55" stop-color="{기본}"/>
    <stop offset="1" stop-color="{그림자}"/>
  </radialGradient>
  <filter id="soft" x="-50%" y="-50%" width="200%" height="200%"><feGaussianBlur stdDeviation="16"/></filter>
  <path id="shape" d="M… C… C… Z"/>                 <!-- 실루엣: 닫힌 Bézier path 하나 -->
  <clipPath id="inShape"><use href="#shape"/></clipPath>
</defs>
<ellipse cx="512" cy="830" rx="230" ry="30" fill="{가장 어두운 색}" opacity="0.18" filter="url(#soft)"/>  <!-- 바닥 그림자 -->
<use href="#shape" fill="url(#body)"/>                                      <!-- 기본 면 -->
<g clip-path="url(#inShape)">
  <path d="{광원 반대편을 덮는 면}" fill="{그림자}" opacity="0.3"/>         <!-- 그림자 면, 본체 안에 갇힘 -->
</g>
<ellipse cx="…" cy="…" rx="…" ry="…" fill="{하이라이트}" opacity="0.5" filter="url(#soft)"/>  <!-- 흐린 하이라이트 -->
<use href="#shape" fill="none" stroke="{외곽선색}" stroke-width="7" stroke-linejoin="round"/>   <!-- 외곽선 -->
<g transform="translate(1024 0) scale(-1 1)"><use href="#part"/></g>      <!-- 반쪽을 뒤집어 대칭 -->
```
