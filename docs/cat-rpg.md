# NekoDesk — 고양이 RPG 설계안

> 작성일: 2026-04-26  
> 목적: 고양이와의 관계를 시간과 돌봄으로 쌓아가는 RPG 레이어 설계

---

## 1. 핵심 방향

- 복잡한 RPG가 아니라 "같이 산다"는 감각
- 기능(메모/할 일/에이전트)을 쓸수록 고양이에게 영향을 주는 구조
- 수치보다 상태와 표정으로 전달

---

## 2. 고양이 나이 (첫 만남 누적일)

### 저장
- 앱 최초 실행 시 `settings` 테이블에 `cat_birthday = "YYYY-MM-DD"` 저장
- 이미 존재하면 건드리지 않음 (한 번만 기록)

### 표시
- 고양이 패널 어딘가에 `Day 42` 형태로 표시
- 만남 첫날은 Day 1

### 구현
```
Rust: settings_get("cat_birthday") → 없으면 오늘 날짜로 settings_set
React: 앱 시작 시 invoke("settings_get", { key: "cat_birthday" }) → 오늘과의 차이를 일 수로 계산
```

---

## 3. 상태 게이지

### 게이지 종류

| 게이지 | 이름 | 최대값 | 설명 |
|--------|------|--------|------|
| 🍚 배고픔 | hunger | 100 | 시간 지나면 감소 |
| 🎾 놀이 | play | 100 | 쓰다듬거나 에이전트 쓰면 증가 |

### 감소/증가 규칙

**hunger**
- 앱 사용 중 10분마다 -5
- 마지막 접속 기준으로 오프라인 시간도 반영 (최대 -60)
- 밥 버튼 클릭 → +40 (단, 하루 3회 제한)

**play**
- 고양이 쓰다듬기 → +10
- 에이전트 루프 완료 → +5
- 메모/할 일 추가 → +2
- 시간 지나면 -3/10분

### 저장
- `settings` 테이블에 `cat_hunger`, `cat_play`, `cat_last_tick` (ISO timestamp) 저장
- 앱 켤 때 오프라인 경과 시간 계산해서 일괄 적용

### 표시
- 고양이 패널 하단에 미니 게이지 바 2개
- 수치 숫자 없이 바 길이만 (숫자는 hover 시 툴팁)
- hunger < 20 이면 주황색, < 10 이면 빨간색
- play < 20 이면 회색으로 흐려짐

---

## 4. 게이지 연동 버튼

```
[ 🍚 밥 주기 ]   [ 🎾 놀아주기 ]
```

- 밥 주기: hunger +40, 고양이가 eating 상태로 잠깐 전환
- 놀아주기: play +20, 고양이가 happy 상태로 잠깐 전환
- 쿨다운 표시 (밥: 하루 3회, 놀이: 제한 없음)

---

## 5. 새 감정 상태: box

### 트리거 조건
- play 게이지 80 이상이고 idle 상태일 때 랜덤하게 box 상태로 전환 (30초~2분 간격)
- 또는 play > 90 이면 더 자주

### 스프라이트
- `mochi-box.png` (추후 추가 필요)
- mochi가 박스 안에 들어가 앉아있거나 들락날락하는 애니메이션
- 현재 mochi-idle과 같은 크기/스케일 유지

### 동작
- box 상태에서 쓰다듬으면 상자에서 나와서 happy → idle
- 일정 시간 후 자동으로 idle 복귀

## 6. 감정 상태 전체 정리 (확장 후)

| 상태 | 트리거 | 스프라이트 |
|------|--------|-----------|
| idle | 기본 | mochi-idle |
| curious | 에이전트 루프 시작 | mochi-idle (일부 프레임) |
| working | 툴 실행 중 | jumpcat |

| error | 에이전트 오류 | mochi-idle (긴장 프레임) |
| **box** | play > 80 랜덤 | mochi-box *(추가 필요)* |

## 7. 고양이 공간 꾸미기

### 개념
- 고양이 패널 배경에 작은 오브젝트들을 배치할 수 있음
- 오브젝트는 픽셀아트 스프라이트
- 처음엔 빈 공간, 조건을 채우면 하나씩 등장

### 오브젝트 목록 (초안)

| 오브젝트 | 등장 조건 | 효과 |
|---------|---------|------|
| 🪣 물그릇 | 기본 제공 | hunger 감소 속도 -10% |
| 📦 박스 | Day 3 이상 | box 상태 트리거 확률 +10% |
| 🪴 화분 | 메모 10개 이상 작성 | 장식 |
| 🎀 리본 | 쓰다듬기 누적 50회 | play 상한 +10 |
| 🌙 달 모빌 | 자정 이후 앱 켠 적 있음 | 장식 |
| 📚 책 | 에이전트 루프 20회 완료 | curious 상태 유지 시간 +50% |

### 저장
- `settings` 테이블: `cat_room_items = '["box","plant"]'` (JSON 배열)
- 조건 충족 시 자동 추가, 알림 없이 조용히

### 렌더링
- 고양이 캔버스 뒤쪽 레이어에 스프라이트로 그림
- 또는 CSS absolute 포지션으로 이미지 배치
- 고양이는 항상 최상단 레이어

## 10. 열린 질문

- 게이지를 Rust(SQLite)에서 관리할지 React state로만 관리할지
  → 오프라인 반영이 필요하므로 SQLite 필수, React는 표시용
- mochi-box 스프라이트 직접 그릴지, 기존 에셋 활용할지
- 오브젝트 등장 시 알림을 줄지 (조용히 등장 vs 말풍선 한 마디)
- 밥 주기 하루 3회 제한을 날짜 기준으로 할지, 24시간 기준으로 할지
