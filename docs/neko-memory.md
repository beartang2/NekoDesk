# 네코의 기억 — 잊기(0.1.29)

> 사용자(2026-11-23): "기억하는 것은 지식처럼 쓰여서 오래됐다고 지우지는 않았으면 좋겠고, 몇백 개 이상 되면 오래된 것부터 조금씩 밀려났으면. 대화하거나 다른 활동에서 기억을 꺼내 활용하면 최근으로 끌어올려서 오래된 기간을 한 번씩 초기화 — 사람처럼." 잊은 기억은 "숨겨서 보관하고, 보관된 기억은 30일 뒤에 지워지게."

## 1. 규칙

- **오래됐다고 지우지 않는다.** 쉴 때 정리(`agent/memory-tidy`: 겹침 합치기, 도구로 찾을 수 있는 사용자 정보 지우기)는 그대로다.
- **마지막으로 쓴 때**(`used_ms`, 처음엔 만든 때): 꺼내 쓰면 지금이 된다.
  - 쓴 것으로 치는 경우
    - 기억 검색(`memory_search`). 대화마다 하는 자동 떠올리기(`recallMemories` — 그 말의 낱말로 찾은 것만)와 기억 검색 도구가 여기에 든다.
    - 생각하기 재료(`mindMaterial` 에 들어간 산책 기억·사용자 기억 — 산책 주제·첫마디·꿈·그림 고르기).
    - 산책 선물 재료로 고른 기억.
    - 같은 것을 다시 저장(다시 알게 됨).
  - 매 요청마다 늘 붙는 고정 재료는 없다. 자동 떠올리기는 그 말과 맞는 것만 나온다.
  - 찍는 간격: 6시간에 한 번(`TOUCH_EVERY_MS`). 순서만 맞으면 되고, 찍을 때마다 동기화 기록이 올라가서다.
- **잊기**(`db::memories::forget`, 쉴 때 — 졸 때마다 `neko/memoryTidy.ts`): 모델을 안 부르니 프로필·예산과 상관없다.
  - 보이는 기억이 상한(기본 300, 설정 › 기억 상한)을 넘으면, 쓴 때가 가장 오래된 것부터 하루(24시간) 최대 5개를 잊는다.
  - 순서는 쓴 때 → 만든 때 → 내용이다(기기마다 다른 번호는 안 본다 — 맥·폰이 같은 순서로).
- **잊은 기억**(`forgot_ms` 가 쓴 때보다 나중): 설정의 "기억하는 것"·생각하기 재료·자동 떠올리기에 안 나온다. 잊은 지 30일이 지나면 지운다(지움 표시로 다른 기기도).
- **되살리기(넣었다)**: 잊은 30일 안에 기억 검색 도구가 그 기억을 찾아 꺼내 쓰면, 쓴 때가 잊은 때보다 뒤로 찍혀 다시 보인다. 같은 것을 다시 저장해도 되살아난다.
  - 넣은 까닭: 사용자가 말한 "사람처럼"에 맞고, 잊었다고 영영 못 떠올리면 30일 보관이 쓸모없다.
  - 자동 떠올리기는 잊은 것을 안 찾는다. 대화마다 낱말만 맞아도 되살아나면 잊기가 거의 일어나지 않는다. 모델이 직접 찾을 때만 되살린다.
- **안전선**: 저장이 1000개(잊은 것 포함)를 넘으면 잊은 것부터, 그다음 오래 안 쓴 것부터 지운다. 예전엔 500개에서 덜 쓴 것부터 지웠다.

## 2. 동기화

- 마이그레이션 13: `memories.used_ms`·`forgot_ms`(ms, 0 = 없음). 기억 기록(`memory`)에 두 칸을 싣는다.
- **받을 때 큰 쪽을 남긴다**(`sync::write_row` 의 `maxed`). 잊음은 "잊은 때 > 쓴 때"라 어느 순서로 받아도 같은 값이 되고, 한쪽이 잊은 뒤 다른 쪽이 쓰면 둘 다 되살아난다.
- 트리거: 두 칸이 바뀌어도 dirty 를 찍는다(`use_count`·`last_used_at` 만 바뀌면 지금처럼 안 찍는다). 13번은 칸만 더해, 올리기로 이미 있던 기억을 다시 올리지 않는다.
- **옛 버전 기기**(0.1.28 까지):
  - 두 칸을 모르고 받으면 버린다. 그 기기에선 잊은 기억도 보인다.
  - 옛 기기가 내용을 고쳐 올린 기록엔 두 칸이 없다. 받는 쪽은 지금 값을 지킨다(없는 칸 = 0, 큰 쪽).
  - 30일 뒤 지움은 지움 표시로 옛 기기에도 간다.
- 다시 맞추기(`sync/reconcile.rs`)는 머리(번호·시각·기기)로만 견주고, 골라 받은 기록은 같은 `apply` → `write_row` 를 거친다.

## 3. 시험

- `db::memories` tests:

  - 상한을 넘어도 하루 5개까지이고, 상한 안이면 안 잊는다.
  - 30일 뒤 지운다.
  - 검색 도구로 찾아 쓰거나 다시 저장하면 되살아난다.
  - 6시간 안엔 다시 안 찍는다.
- `sync::tests`:
  - 두 기기에서 잊음·되살림이 어느 순서로든 맞는다.
  - 옛 기기 기록은 두 칸을 지킨다.
  - 13번은 다시 올리지 않는다.
- `neko-mind.test`: 재료로 들어간 기억만 찍는다(사실을 안 보이는 생각하기면 사실 기억은 안 찍는다).
- `memoryCap.test`: 상한 범위를 본다.
