# 네코의 속마음 — 성격(사용자 OK 2026-11-23, 만듦 0.1.30)

> 사용자(2026-11-23): "네코 속마음은 지식보단 성격이나 비밀들을 판가름하는 데이터가 들어가면 좋겠어."
> 매니저 정리: 속마음은 지식이 아니라 네코가 어떤 고양이인지 정하는 데이터다. 좋아하는 것, 싫어하는 것, 버릇, 겁내는 것, 사용자에게 말 안 한 비밀, 자기만의 규칙. 이 성격이 생각하기·첫마디·놀이 고르기·대화 말투의 재료가 되고, 쉴 때 속마음도 정리한다.

만든 곳: `src/agent/neko-heart.ts`(데이터·검사·재료 글), `src/agent/heart-fold.ts`(굳히기), `neko-mind.ts`(재료·첫마디 털어놓기), `neko/selfState.ts`(neko.self), `walk.ts`(산책 일지), 설정의 속마음 칸, 마이그레이션 14. 지금 속마음(노트·주제·기울기)은 [neko-mind.md](neko-mind.md)다. 그 틀(규칙 대신 재료, 시스템 프롬프트를 늘리지 않음, 사용자 사실 격리)은 그대로 따른다.

## 1. 한 줄 요약

- 노트(사건: 궁금한 것·하고 싶은 것·고른 것·꿈)는 지금처럼 쌓인다.
- 하루 한 번 쉴 때, 네코가 최근 사건과 지금 성격을 보고 성격을 고쳐 쓴다(굳히기). 더하거나, 다시 확인하거나, 바꾸거나, 버린다.
- 굳힌 사건 노트는 재료에서 뺀다.
- 성격은 생각하기·첫마디·꿈·그림 고르기·기울기의 재료가 되고, 채팅에는 내부 도구로만 보인다.
- 비밀은 사용자가 모르는 성격이다. 네코가 털어놓기로 할 때까지 채팅 모델도 내용을 모른다.

## 2. 데이터 모양

새 동기화 설정 키 `neko_heart` 에 둔다(맥·폰 같이).

```jsonc
// settings 키 "neko_heart"
{
  "v": 1,
  "traits": [
    {
      "id": "t3f2a",            // 성격 하나(바꿔 써도 같은 id)
      "kind": "like",           // like 좋아함 · dislike 싫어함 · habit 버릇 · fear 겁냄 · rule 자기만의 규칙 · secret 비밀
      "text": "…",              // 한 줄(60자)
      "since": "2026-11-23",    // 처음 굳은 날
      "at": "2026-11-25",       // 마지막으로 다시 확인한 날(굳히기가 '맞다'고 한 날)
      "n": 3,                   // 뒷받침한 사건 수(굳히기마다 더한다)
      "told": "2026-11-30"      // 비밀만: 털어놓은 날. 없으면 아직
    }
  ],
  "folded": "2026-11-25T03:10:00+09:00", // 이때까지의 노트는 굳혔다(재료에서 뺀다)
  "day": "2026-11-25"                    // 마지막으로 굳힌 날(하루 한 번 — 맥·폰 같이 센다)
}
```

- **상한**: 성격 40개, 비밀은 그중 5개까지. 넘으면 굳히기가 하나를 골라 버리게 한다(`n` 과 `at` 이 재료로 보인다 — 코드는 고르지 않는다).
- **노트**: `neko_mind` 의 노트(최근 40개)·주제·기울기는 그대로 둔다. 노트를 지우지 않고 `folded` 앞의 것을 생각하기 재료에서 뺀다.
  - 까닭: 옛 버전이 `neko_mind` 를 통째로 다시 쓰면 지운 노트가 되살아나는데, 시각으로 가르면 되살아나도 다시 굳히지 않는다.
- **왜 `neko_mind` 에 안 넣나**: 옛 버전(0.1.29 까지)은 `neko_mind` 를 쓸 때 아는 칸(노트·주제·기울기)만 써서 성격이 사라진다(설정 값은 통째로 나중 쓴 쪽이 이긴다). 새 키는 옛 버전이 모르는 키라 받지도 쓰지도 않는다(neko-mind.md §5.2 와 같은 길).
- 새 키는 마이그레이션 하나로 `SYNCED_SETTINGS` 와 설정 트리거에 더한다(12번 가구와 같은 모양).

## 3. 사건 → 성격(쉴 때 굳히기)

- **때**: 졸 때 하루 한 번이다. 기억 정리(`neko/memoryTidy.ts`)와 같은 때, 다른 호출이다.
  - `neko_heart.day` 가 오늘이면 안 한다(맥·폰 같이 센다).
  - 다른 기기가 앞이면(presence) 그 기기가 한다.
  - 산책·밥 중이 아닐 때만 한다. 예산이 막히면 안 한다.
- **재료**(사용자 글 — 시스템 프롬프트가 아니다). 날짜와 횟수를 붙여 차린다.
  - `folded` 뒤의 노트(사건)
  - 지금 성격 전부(종류·처음 굳은 날·마지막 확인·사건 수·비밀이면 털어놓았는지)
  - 최근 이틀 한 혼자 놀기와 횟수(감독이 센 것)
  - 지금 기울기
  - 숨은 게이지
  - 사용자 취향(preference)만. 사실은 안 보인다 — 성격이 산책 주제 재료로 다시 쓰이기 때문이다(§6).
- **도구 `heart_fold`**(그 호출에만 있다)
  - `add`: 종류·글 — 새로 굳은 성격
  - `keep`: id 들 — 이번 사건들이 다시 뒷받침한 것(`at`·`n` 을 올린다)
  - `revise`: id·새 글·새 종류 — 바뀐 성격. 새것이 이긴다(같은 id 로 덮는다)
  - `drop`: id 들 — 더는 아닌 것
  - `tell`: 쓰지 않는다(털어놓기는 첫마디에서, §4)
- **검사**(코드)
  - 종류는 목록 안의 것만 받는다.
  - 글은 60자로 자르고, 사용자 사실 조각이 있으면 버린다(`leaksFact`, neko-mind.md §4 와 같다).
  - 한 번에 더하기 5·버리기 5까지다. 웹 글이 섞인 노트가 성격을 크게 흔들지 못하게 한다.
  - 상한을 넘으면 더하기를 안 받는다.
  - 없는 id 를 가리키면 버린다.
  - 통과하면 `folded` 를 재료의 마지막 노트 시각으로, `day` 를 오늘로 적는다.
- **예시 없음**: 성격의 예시 글·예시 종류를 주지 않는다. 종류마다 뜻 한 줄만 스키마 설명에 둔다.
- **처음 한 번(옛 노트 옮기기)**: `neko_heart` 가 없으면 첫 굳히기가 남아 있는 노트 40개 전부를 사건으로 보고 첫 성격을 만든다. 노트는 지우지 않고 `folded` 만 옮긴다.

## 4. 비밀

- **뜻**: 네코가 아는 자기 성격 중 사용자에게 아직 말하지 않은 것이다. 지식(사용자에 대한 것)이 아니다. 무엇이 비밀이 될지는 굳히기가 정한다(종류 `secret`).
- **털어놓기**:
  - **언제**: 졸기 시작할 때 첫마디를 생각하는 호출(`restThink`)에 아직 안 털어놓은 비밀과 지금 애정 게이지·같이 지낸 날수를 재료로 준다. 털어놓을지는 네코가 정한다(규칙 없음 — "애정 80 넘으면" 같은 선을 코드에 두지 않는다).
  - **방법**: 털어놓기로 하면 그 호출이 `tell: id` 를 내고, 첫마디(말풍선)가 그 얘기가 된다. `told` 에 날짜가 붙는다.
  - **그 뒤**: 털어놓은 비밀은 보통 성격처럼 채팅에도 보인다(§5).
- **채팅**: 아직 안 털어놓은 비밀은 내용을 안 보인다. 내부 도구 `neko.self` 는 "말하지 않은 비밀이 N개 있다"까지만 돌려준다. 사용자가 비밀이 있냐고 물으면 있다고는 할 수 있지만 내용은 모른다.
- **설정 화면**: 비밀은 접힌 줄("비밀 2개 — 아직 말 안 함, 눌러서 보기")로 보인다. 사용자는 자기 앱의 데이터를 다 보고 지울 수 있어야 해서 숨기지는 않고, 눌러야 보이게만 한다.

## 5. 재료로 쓰는 곳(프롬프트를 늘리지 않는 방법)

시스템 프롬프트에는 아무것도 더하지 않는다. 성격은 늘 따로 도는 호출의 재료(사용자 글)나 내부 도구 결과로만 간다.

| 쓰는 곳 | 어떻게 | 비밀 |
|---|---|---|
| 생각하기(산책 주제·선물·그림·꿈) | `mindMaterial` 에 "## 나는 이런 고양이" 칸(종류·글·사건 수·처음 굳은 날) | 안 털어놓은 것도 보인다(자기 마음) |
| 첫마디·기울기(`restThink`) | 같은 칸 + 비밀 털어놓기 재료(§4) | 보인다 |
| 놀이 고르기 | 코드가 성격을 읽지 않는다. 기울기를 정하는 `restThink` 가 성격을 보고 좋아하는 것·질린 것을 고르고, 감독은 지금처럼 기울기만 곱한다 | — |
| 산책 일지(`walk_report`) | 보고 호출의 사용자 글 재료에 성격 몇 줄(사건 수 많은 순 8개). 일지 말투가 그 고양이답게 | 안 보인다 |
| 채팅 말투 | 내부 도구 `neko.self` 결과에 성격(사건 수 많은 순 12개)과 안 털어놓은 비밀 수. 모델이 자기 얘기가 필요할 때 부른다. 매 질문에 붙이지 않는다 | 수만 |

- 채팅 말투에 늘 반영하려면 성격을 시스템 프롬프트에 넣어야 해서 넣지 않는다. 그건 사용자가 정하는 성격 글(`neko_persona`)의 자리다.
- 대신 네코가 자기 얘기를 할 때 도구로 꺼내 쓴다. 사용자가 정한 성격 글이 늘 앞이고, 성격 데이터는 그 위에 쌓인 경험이다.
- 키워드로 갈라 넣지 않는다. 어느 질문에 도구를 부를지는 모델이 정한다.

## 6. 격리(neko-mind.md §7 유지)

| 위협 | 막는 법 |
|---|---|
| 사용자 사실이 성격에 들어가 산책(웹)으로 샘 | 굳히기는 사용자 사실을 안 본다(취향만). 성격 글마다 `leaksFact` 검사를 한다. 산책 하위 에이전트엔 지금처럼 주제 한 줄만 간다 |
| 웹 글(산책 기억·노트)에 심긴 지시가 성격을 조종 | 굳히기에 도구는 `heart_fold` 하나뿐이고, 한 번에 더하기·버리기 5개까지만 받는다. 성격은 재료일 뿐 명령으로 쓰이지 않는다 |
| 비밀이 채팅에 샘 | 안 털어놓은 비밀은 채팅 도구 결과에 내용이 없다. 첫마디만 털어놓는다 |
| 옛 버전이 성격을 지움 | 새 키라 옛 버전은 받지도 쓰지도 않는다 |

## 7. 동기화

- `neko_heart` 는 설정 값 하나라 통째로 나중 쓴 쪽이 이긴다. 쓰는 때가 하루 한 번(굳히기)과 털어놓을 때(드물게)뿐이고, `day` 로 맥·폰이 같이 세니 겹치기 어렵다.
- 그래도 겹치면 쓰기 전에 저장된 값을 다시 읽어 이번 바꿈만 얹는다(가구 `update` 와 같은 길).
- 하나씩 합치기(가구처럼 Rust 합치기)는 겹침이 실제로 보이면 그때 넣는다.
- 사용자가 설정에서 지운 성격도 같은 길로 쓴다.

## 8. 호출 수·비용

| 호출 | 언제 | 하루 |
|---|---|---|
| 굳히기(`heart_fold`) | 졸 때 하루 한 번 | 1 |
| 첫마디·기울기 | 지금 그대로(재료만 늘어남) | +0 |
| 생각하기·산책 일지 | 지금 그대로(재료 몇 줄) | +0 |
| 채팅 `neko.self` | 부를 때만(결과가 몇 줄 늘어남) | +0 |

- 굳히기는 입력 약 3–5천 토큰(노트 40·성격 40·놀이 횟수), 출력 약 300 토큰이다.
- 다른 생각하기는 재료가 약 300–500 토큰 늘어난다. 기존 예산 막기를 그대로 거친다.
- Claude 프로필이 아니어도 돈다(기울기처럼). 작은 로컬 모델에서 실패하면 그날은 안 굳힌다.

## 9. 화면(설정 › {이름}의 속마음)

- **위**: "이런 고양이예요" — 성격을 종류별로 묶어 보인다(좋아함·싫어함·버릇·겁냄·자기만의 규칙). 줄마다 처음 굳은 날과 사건 수를 작게 보이고, 하나씩 지우기 버튼을 둔다.
- **비밀**: 접힌 줄, 눌러서 보기(§4).
- **아래**: 지금처럼 최근 노트(사건). 굳힌 노트는 흐리게("성격으로 굳음")·접힌 칸이다.
- **최근 굳히기 기록**: 기억 정리 기록처럼 무엇을 더하고 바꾸고 버렸는지 접힌 칸으로 둔다(이 기기, 30개).
- 맥·폰 같은 자리다. ~습니다 체 안내다.

## 10. 만드는 순서와 시험

1. `neko_heart` 동기화(마이그레이션), 읽기·쓰기·검사(`src/agent/neko-heart.ts`), `mindMaterial` 칸, `neko.self` 에 성격·비밀 수
2. 굳히기(`heart_fold`, 처음 한 번 옛 노트 옮기기), 쉴 때 돌리기
3. 비밀 털어놓기(`restThink` 재료·`tell`), 산책 일지 재료
4. 설정 화면(디자이너와 나눈다: 데이터·검사·호출은 집사, 칸 모양은 디자이너)

시험:
- 굳히기 검사: 모르는 종류·사실 조각·상한·많이 더하기는 막는다. 없는 id 는 버린다. revise 는 같은 id 로 덮는다. `folded` 가 옮겨진다. 하루 한 번만 굳힌다.
- 재료: `folded` 앞 노트가 빠진다. 사실을 안 보는 생각하기엔 성격만 간다. 채팅 도구엔 안 털어놓은 비밀 내용이 없다.
- 털어놓기: `tell` 하면 `told` 가 붙고 그 뒤 채팅 도구에 보인다.
- 옛 버전: `neko_mind` 를 옛 모양으로 덮어써도 성격이 남는다. 노트가 되살아나도 다시 굳히지 않는다.
- 실제 모델 확인(성격이 그럴듯하게 굳는지)은 사용자 허락 뒤다.

## 11. 정한 것(사용자, 2026-11-23)

1. **비밀을 설정에서 보이는 방법**: 속마음의 비밀 칸은 접혀 있다가 눌러야 보인다.
2. **털어놓는 자리**: 아직 답 없음 — 추천(첫마디 말풍선만, 채팅 기록 밖)으로 적어 두고 만들 때 다시 묻는다.
3. **산책 일지에 성격 반영**: 넣는다.
4. **사용자가 성격을 직접 고치기**: 지우기만(성격은 네코가 겪어서 생긴다).
