# 네코의 속마음 — 어떤 생각을 하는 고양이인가(0.1.30 성격 → 2026-11-24 갈래 개편, 사용자 OK)

> 사용자(2026-11-23): "네코 속마음은 지식보단 성격이나 비밀들을 판가름하는 데이터가 들어가면 좋겠어."
>
> 사용자(2026-11-24):
> - "유르미 속마음에 고름: 놀이 같은 것들은 안 들어오게 해 줘."
> - "그냥 기억하는 것으로 들어가는 내용들이 자꾸 속마음 → 성격 쪽으로 들어오니까 좀 이상하긴 해."
> - "최근 관심사나 교양, 철학, 성격, 가치관, 정체성 이런 내용이 속마음에 있었으면 하는 거야. 지금 속마음에 있는 내용들 대부분은 거의 그냥 네코가 기억하는 것으로 들어가도 무방한 내용들뿐이야."

속마음은 "네코가 어떤 생각을 하는 고양이인가"만 담는다. 알게 된 사실은 기억(memories)으로 가고, 무엇을 골랐는지 같은 행동 기록은 담지 않는다.

만든 곳:
- `src/agent/neko-heart.ts`: 데이터·검사·재료 글
- `src/agent/heart-fold.ts`: 굳히기
- `neko-mind.ts`: 재료·첫마디 털어놓기
- `neko/selfState.ts`: neko.self
- `walk.ts`: 산책 일지
- 설정의 속마음 칸
- 마이그레이션 14(옛 키)·16(새 키)

노트·주제·기울기는 [neko-mind.md](neko-mind.md)에 있다. 그 틀은 그대로 따른다: 규칙 대신 재료, 시스템 프롬프트를 늘리지 않음, 사용자 사실 격리.

## 0. 이번에 바꾸는 것(2026-11-24)

| | 전(0.1.30–0.1.31) | 후 |
|---|---|---|
| 갈래 | 좋아함·싫어함·버릇·겁냄·자기만의 규칙·비밀 | 관심사·교양·철학·성격·가치관·정체성·비밀(§2) |
| 사실·알게 된 것 | 성격 줄로 굳기도 함 | 굳히기가 기억(memories, 종류 `neko`)으로 보낸다(§3) |
| 고른 기록(`chose` 노트) | 노트에 쌓이고 성격 재료가 됨 | 안 쓴다. 예전 것도 읽을 때 버린다. 산책 주제는 '알아본 주제' 목록에만 남는다 |
| 지금 있는 성격 | — | 업데이트 뒤 첫 굳히기가 한 번 훑어 갈래를 바로잡거나 기억으로 옮긴다(§3.3) |
| 저장 키 | `neko_heart` | `neko_heart2`(§2.2 — 옛 버전이 새 갈래를 지우지 못하게) |
| 설정 화면 | 성격 + 노트 목록 | 새 갈래 + 접힌 비밀 + 접힌 노트(§9) |
| 하루 호출 수 | 굳히기 1 | 그대로 1 |

먼저 들어간 것(우체부 6dd5174, neko-v26 에 d5f9623 으로 가져옴):
- 선물 종류 고름은 노트에 안 남긴다.
- 고름 노트는 굳히기 재료에서 뺀다.
- "성격으로 굳음" 표시를 고름 줄에 안 단다.

이번 개편이 이것을 넓힌다: 고름 노트 자체를 없앤다.

## 1. 한 줄 요약

- 노트(사건: 궁금한 것·하고 싶은 것·꿈)는 지금처럼 쌓인다. 고른 것은 노트가 아니다.
- 하루 한 번 쉴 때, 네코가 최근 사건과 지금 속마음을 보고 속마음을 고쳐 쓴다(굳히기).
  - 더하기·다시 확인하기·바꾸기·버리기는 그대로다.
  - 성격이 아니라 알게 된 사실은 기억으로 보낸다.
- 굳힌 사건 노트는 재료에서 뺀다.
- 속마음은 생각하기·첫마디·꿈·그림 고르기·기울기의 재료가 된다. 채팅에는 내부 도구로만 보인다.
- 비밀은 사용자가 모르는 속마음이다. 네코가 털어놓기로 할 때까지 채팅 모델도 내용을 모른다.

## 2. 데이터 모양

### 2.1 갈래

| 키 | 이름 | 뜻(굳히기 스키마 설명에 이 한 줄만 둔다 — 예시 없음) | 옛 갈래에서 |
|---|---|---|---|
| `interest` | 관심사 | 요즘 마음이 가는 주제나 분야 | 좋아함 |
| `culture` | 교양 | 알아 가며 즐기게 된 앎과 문화 | — |
| `philosophy` | 철학 | 세상과 삶을 보는 생각 | — |
| `temper` | 성격 | 타고난 성질, 버릇, 겁내는 것 | 버릇·겁냄 |
| `value` | 가치관 | 소중히 여기는 것과 싫은 것, 스스로 지키는 규칙 | 싫어함·자기만의 규칙 |
| `identity` | 정체성 | 스스로를 어떤 고양이라고 여기는지 | — |
| `secret` | 비밀 | 사용자에게 아직 말하지 않은 마음 | 비밀 |

- **관심사는 '요즘'이다**: 코드가 오래된 것을 지우지 않는다. 굳히기가 줄마다 마지막 확인 날·사건 수를 보고 더는 아닌 것을 버린다(drop).
- **옛 갈래 옮기기**: 읽을 때 위 표대로 바꿔 둔다. 좋아함이 다 관심사는 아니라서, 맞는 갈래는 첫 굳히기가 바로잡는다(§3.3).

### 2.2 저장

새 동기화 설정 키 `neko_heart2` 에 둔다(맥·폰 같이).

```jsonc
// settings 키 "neko_heart2"
{
  "v": 2,
  "traits": [
    { "id": "t3f2a", "kind": "value", "text": "…", "since": "2026-11-23", "at": "2026-11-25", "n": 3, "told": "2026-11-30" }
  ],
  "folded": "2026-11-25T03:10:00+09:00", // 이때까지의 노트는 굳혔다
  "day": "2026-11-25",                   // 마지막으로 굳힌 날(하루 한 번)
  "review": true                         // 옛 키에서 옮겨 와 아직 한 번 훑지 않음(§3.3). 훑으면 지운다
}
```

- **왜 새 키인가**: 옛 버전(0.1.30–0.1.31, 이미 배포됨)은 `neko_heart` 를 읽을 때 모르는 갈래를 버린다.
  - 그 버전이 굳히기·지우기·털어놓기로 값을 다시 쓰면 새 갈래 줄이 다 사라진다.
  - 맥·폰 중 한쪽만 업데이트된 동안 실제로 일어날 수 있다.
  - 새 키는 옛 버전이 모르는 키라 받지도 쓰지도 않는다(0.1.30 이 `neko_mind` 대신 `neko_heart` 를 쓴 것과 같은 길).
- **옮겨 오기**: `neko_heart2` 가 없으면 `neko_heart` 를 읽어 §2.1 표대로 갈래를 바꾸고 `review: true` 를 붙인다.
  - 처음 쓸 때 새 키에 저장된다.
  - 옛 키는 그대로 둔다. 옛 버전 기기는 그걸 계속 쓰고, 새 버전은 다시 읽지 않는다.
- **마이그레이션 16**: `neko_heart2` 를 `SYNCED_SETTINGS` 와 설정 트리거에 더한다. 14·15번과 같은 모양이다.
- **상한**: 그대로 둔다.
  - 속마음 40개, 그중 안 털어놓은 비밀 5개, 한 줄 60자.
  - 넘으면 굳히기가 버릴 것을 고른다.
- **노트**: `neko_mind` 의 노트(최근 40개)·주제·기울기는 그대로다.
  - 노트 종류는 `wonder`·`want`·`dream` 셋이다.
  - `chose` 는 쓰지 않고, 읽을 때 버린다(옛 버전이 다시 써도 새 버전은 안 본다).

## 3. 사건 → 속마음(쉴 때 굳히기)

### 3.1 때·재료

- **때**는 그대로다.
  - 졸 때 하루 한 번, `day` 로 맥·폰이 같이 센다.
  - 앞 기기만 한다. 산책·밥 중엔 안 한다. 예산이 막히면 안 한다.
- **재료**(사용자 글 — 시스템 프롬프트가 아니다)는 그대로다.
  - `folded` 뒤의 노트
  - 지금 속마음 전부(번호·갈래·사건 수·날짜)
  - 알아본 주제(갈래·횟수)
  - 네코가 알게 된 것(기억 `neko`)
  - 최근 이틀 혼자 놀기
  - 기울기·게이지
  - 사용자 취향(preference)만. 사실은 안 보인다.
- 고름 노트는 이제 없으니 재료에서 빼는 일도 없다.

### 3.2 도구 `heart_fold`(그 호출에만 있다)

- `add`: 갈래·글 — 새로 굳은 것
- `keep`: 번호들 — 이번 사건들이 다시 뒷받침한 것
- `revise`: 번호·새 글·새 갈래 — 바뀐 것. 같은 번호로 덮는다
- `drop`: 번호들 — 더는 아닌 것
- **새로** `remember`: 글들 — 사건 중 속마음이 아니라 기억해 둘 사실·알게 된 것이다. 기억(종류 `neko`)으로 저장한다.
- **새로** `move`: 번호들 — 지금 속마음 중 실은 사실·알게 된 것인 줄이다. 그 글을 기억(`neko`)으로 저장하고 속마음에서 뺀다.

할 일 글(그 호출의 사용자 글 끝, 한 줄)도 바꾼다.
- 전: "어떤 고양이인지 성격을 고쳐 써"
- 후: "네가 어떤 생각을 하는 고양이인지(관심사·교양·철학·성격·가치관·정체성·비밀) 고쳐 써. … 사건 중 속마음이 아니라 알게 된 사실은 remember, 지금 속마음 중 그런 것은 move."

갈래 뜻은 스키마 설명(§2.1 한 줄씩)에만 둔다. 예시 글·예시 갈래는 주지 않는다.

**검사**(코드):
- 갈래는 목록 안의 것만 받는다.
- 글은 60자로 자른다.
- 사용자 사실 조각이 든 글은 버린다(`leaksFact`). `remember`·`move` 도 같은 검사를 거친다.
  - 기억 `neko` 는 산책 하위 에이전트의 재료가 되므로 사실 조각이 들어가면 안 된다.
- 한 번에 `add`·`drop`·`remember`·`move` 각 5개까지만 받는다.
- 없는 번호는 버린다.

**기록**: 굳히기 기록(이 기기 30개)에 "기억으로" 줄을 더한다. 무엇이 어디로 갔는지 보이게 한다.

### 3.3 한 번 훑기(지금 있는 속마음 정리)

`review: true` 일 때의 첫 굳히기다. 따로 부르지 않고 그날의 굳히기 한 번이 한다.

- 사건: `folded` 와 상관없이 남아 있는 노트 전부(최대 40)를 사건으로 본다.
- 할 일 글에 한 줄을 더한다: "지금 속마음은 옛 갈래에서 옮겨 온 것이다 — 줄마다 갈래를 바로잡거나(revise) 사실이면 기억으로 옮겨(move)."
- 이번만 `move`·`drop`·`remember` 상한을 40으로 연다. 대부분이 기억으로 갈 수 있다(사용자).
  - `add` 는 5 그대로다. 웹 글이 섞인 노트가 한 번에 많이 굳지 못하게 한다.
- 통과하면 `review` 를 지운다.
- 실패하면(모델 실패·시간 초과) `review` 가 남아 다음 날 다시 한다. 하루 한 번 규칙은 그대로다.
- 사용자 사실 격리는 그대로다. 훑기 호출도 사용자 사실을 안 보고, 옮기는 글마다 `leaksFact` 를 거친다.

## 4. 비밀(그대로)

- **뜻**: 사용자에게 아직 말하지 않은 네코의 마음이다(갈래 `secret`). 지식(사용자에 대한 것)이 아니다.
- **털어놓기**: 졸기 시작할 때 첫마디를 생각하는 호출(`restThink`)에 안 털어놓은 비밀과 애정·같이 지낸 날수를 재료로 준다.
  - 털어놓을지는 네코가 정한다. 털어놓으면 `tell` → 첫마디 말풍선이 되고, `told` 날짜가 붙는다.
- **채팅**: 안 털어놓은 비밀은 내용이 없다. `neko.self` 는 수만 돌려준다.
- **설정**: 접힌 칸에 두고, 눌러야 보인다.

## 5. 재료로 쓰는 곳(프롬프트를 늘리지 않는 방법)

시스템 프롬프트에는 아무것도 더하지 않는다. 쓰는 곳은 그대로다. 줄의 갈래 이름만 새 갈래로 바뀐다.

| 쓰는 곳 | 어떻게 | 비밀 |
|---|---|---|
| 생각하기(산책 주제·선물·그림·꿈) | `mindMaterial` 의 "## 나는 이런 고양이" 칸. 관심사·교양이 산책 주제 고르기에 그대로 재료가 된다 | 보인다(자기 마음) |
| 첫마디·기울기(`restThink`) | 같은 칸 + 털어놓기 재료 | 보인다 |
| 놀이 고르기 | 코드가 속마음을 읽지 않는다. `restThink` 가 보고 기울기를 정한다 | — |
| 산책 일지(`walk_report`) | 사건 수 많은 순 8줄 | 털어놓은 것만 |
| 채팅(`neko.self`) | 사건 수 많은 순 12줄 + 안 털어놓은 비밀 수. "내 성격" 머리를 "내 속마음" 으로 | 수만 |

- `mindMaterial` 의 "## 산책에서 알게 된 것" 머리는 "## 내가 알게 된 것" 으로 바꾼다. 기억 `neko` 에 굳히기가 옮긴 것도 들어가기 때문이다.
- 갈래로 가르는 코드(키워드 분기)는 두지 않는다. 어느 갈래를 어디에 쓸지는 모델이 재료를 보고 정한다.

## 6. 격리(neko-mind.md §7 유지)

| 위협 | 막는 법 |
|---|---|
| 사용자 사실이 속마음·기억 `neko` 에 들어가 산책(웹)으로 샘 | 굳히기는 사용자 사실을 안 본다(취향만). `add`·`revise`·`remember`·`move` 글마다 `leaksFact` 검사를 한다 |
| 웹 글에 심긴 지시가 속마음을 조종 | 굳히기 도구는 `heart_fold` 하나뿐이다. 더하기는 늘 5개까지다. 옮기기·버리기를 많이 받는 건 한 번 훑기 때뿐이고, 옮긴 글은 기억 목록에 보이며 지울 수 있다 |
| 비밀이 채팅에 샘 | 그대로(내용 없음) |
| 옛 버전이 새 속마음을 지움 | 새 키 `neko_heart2`(§2.2) |

## 7. 동기화

- `neko_heart2` 는 설정 값 하나라 통째로 나중 쓴 쪽이 이긴다. 쓰기 전에 저장된 값을 다시 읽어 이번 바꿈만 얹는다(그대로).
- 옮긴 기억은 memories 표라 기억 동기화로 간다(지금 길 그대로).
- 두 기기가 같은 날 각자 옛 키에서 옮겨 와 훑으면, `day` 가 아직 없어 둘 다 훑을 수 있다. 한 번뿐인 일이고, 나중에 쓴 쪽이 이긴다.
  - 옮긴 기억은 글이 같으면 하나로 합쳐진다(`memory_save` ON CONFLICT).

## 8. 호출 수·비용

| 호출 | 언제 | 하루 |
|---|---|---|
| 굳히기(`heart_fold`) | 졸 때 하루 한 번(첫날은 한 번 훑기를 겸한다) | 1 |
| 그 밖 | 그대로 | +0 |

- 한 번 훑기는 입력 약 4–6천 토큰(노트 40·속마음 40), 출력 약 600 토큰이다. 한 번뿐이다.

## 9. 화면(설정 › {이름}의 속마음)

- **안내**(~습니다 체): {이름}이 어떤 생각을 하는 고양이인지입니다. 졸 때 하루 한 번 최근 노트를 보고 관심사·교양·철학·성격·가치관·정체성을 정리하고, 알게 된 사실은 '기억하는 것'으로 옮깁니다. 맥과 폰이 같이 씁니다.
- **위**: 속마음을 갈래 순서(관심사·교양·철학·성격·가치관·정체성)로 보인다.
  - 줄 모양은 지금 그대로다: 갈래 칩·글·사건 수·처음 날·지우기.
- **비밀**: 접힌 줄 그대로다.
- **노트**: 목록을 펼쳐 두지 않고 접힌 칸 "최근 노트 N개" 로 둔다(사건 — 정리의 재료).
  - 펼치면 지금처럼 쪽 넘김·지우기가 된다.
  - 정리된 노트는 흐리게만 보인다. "성격으로 굳음" 글자는 뺀다.
  - 두 번째 안내 문단은 뺀다.
- **정리 기록**: 접힌 칸 그대로다. "기억으로: …" 줄이 더해진다.
- **기억하는 것 칸**: 종류 `neko` 의 칩 이름을 "산책" 에서 "네코" 로 바꾼다. 굳히기가 옮긴 것도 들어오기 때문이다.
- 맥·폰 같은 자리다. 줄이 길면 지금처럼 접고 눌러 펼친다. 가로로 넘치지 않는다.

## 10. 만드는 순서와 시험

1. 갈래·새 키·옮겨 오기(`neko-heart.ts`), 마이그레이션 16
2. 고름 노트 없애기(`neko-mind.ts` 산책 주제·그림, `parseMind`)
3. 굳히기 `remember`·`move`·한 번 훑기(`heart-fold.ts`)
4. 재료 머리 이름(`mindMaterial`·`neko.self`), 설정 화면

시험:
- 옮겨 오기: 옛 키의 갈래가 표대로 바뀌고 `review` 가 붙는다. 새 키가 있으면 옛 키를 안 본다.
- 굳히기 검사:
  - 모르는 갈래·사실 조각·없는 번호는 버린다.
  - `remember`·`move` 는 기억으로 가고, `move` 한 줄은 속마음에서 빠진다.
  - 평소 상한은 5, 훑기 때는 40이다. 훑으면 `review` 가 지워진다.
- 노트: 옛 `chose` 줄은 읽을 때 빠진다. 산책 주제를 골라도 노트가 안 생긴다(알아본 주제엔 남는다).
- 마이그레이션 16 뒤 `neko_heart2` 가 동기화 기록에 찍힌다.
- 실제 모델 확인(훑기가 그럴듯하게 나누는지)은 사용자 허락 뒤다.
