# NekoDesk 미니게임 설계

## 게임 개요
네코가 제시어를 주면 유저가 그림을 그리고, 네코(LLM + 이미지 인식)가 맞추는 Quick Draw 스타일 게임.

---

## 진입 / 종료

- **시작**: 메뉴 버튼 "미니게임" 탭 + 채팅에서 "게임 하자" 등 말하면 네코가 시작
- **종료**: X 버튼 또는 ESC

---

## UI 레이아웃

채팅창 위에 풀 오버레이로 표시.

```
┌─────────────────────────────────┐
│  제시어: "고양이"   ⏱ 00:28    │
│                                 │
│  ┌───────────────────────────┐  │
│  │                           │  │
│  │        그림판 캔버스       │  │
│  │                           │  │
│  └───────────────────────────┘  │
│  🐱 "혹시 강아지야...?" ←말풍선 │  ← 그림판 왼쪽 아래, 팝업 패널
│  [지우기] [↩] [↪]  [제출하기]  │
└─────────────────────────────────┘
```

---

## 시작 화면 (모드 선택)

게임 진입 시 라운드 수와 모드를 먼저 선택.

```
┌─────────────────────────────┐
│     🐱 어떻게 그릴 거야?    │
│                             │
│   라운드:  [3판]  [5판]     │
│                             │
│   모드:  [흑백]  [컬러]     │
│                             │
│        [시작하기]           │
└─────────────────────────────┘
```

---

## 모드

| | 흑백 모드 | 컬러 모드 |
|---|---|---|
| 색상 | 검정 단색 | 컬러 펜 선택 |
| 제한시간 | 30초 | 60초 |

---

## 게임 흐름

1. 시작 화면에서 모드 + 라운드 선택
2. 네코가 제시어 제시 (LLM 생성, 단일 명사, 라운드 간 중복 없음) + 타이머 시작
3. 유저가 캔버스에 그림 그리기
4. 타이머 종료 또는 "제출하기" 클릭
5. 캔버스 캡처 → LLM 이미지 인식으로 전송
6. 네코가 추측 → 정답 `happy` / 오답 `sad`
7. 다음 라운드 반복 → 전체 종료 시 결과 표시

---

## 그림판 도구

- 펜 굵기: 3단계
- 컬러 모드: 색상 팔레트 제공
- 전체 지우기 버튼
- Undo / Redo

---

## 네코 연동

- 추측 중: `curious` 감정 + 말풍선 (그림판 왼쪽 아래 팝업, 그림판 안 가림)
- 정답: `happy`
- 오답: `sad`
- 힌트 기능 없음

---

## 제시어

- LLM이 매 라운드 단일 명사 생성
- 라운드 내 중복 금지

---

## 점수

- 네코가 맞추면 +1점
- 종료 시 결과 표시 ("5판 중 3판 맞췄어!")
